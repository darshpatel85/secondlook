How a review goes

Most AI reviewers leave a pile of comments. Second Look works through the change with you instead.

  1. 1

    Paste a pull request

    Second Look checks out the branch in its own worktree and reads the diff, the repository's docs and your review guide.

  2. 2

    Agree what it's for

    The agent reads the ticket and design, sums up the intent, and asks you only what the code can't answer.

  3. 3

    Walk the change together

    The change is split into steps and routed by risk. You read the risky parts closely and skim the rest.

  4. 4

    Post what you accept

    Accepted findings go to GitHub as one review, written the way a friendly teammate would write them.

Built for reviewers, not dashboards

Finding verifier

Each finding gets a second, read-only run that tries to prove it wrong. Refuted ones are folded away, not deleted.

Risk routing

Low-risk steps are left to the agent and the verifier. High-risk steps get your full attention. You can change any step.

Context the tests can't see

Before reviewing lines, the agent records what uses the changed code, the data it touches and which code covers each acceptance criterion.

Evidence on every finding

Blocking findings need file and line evidence. If the agent can't show it, the finding becomes a question instead.

Memory per repository

After each review it suggests what to remember about your preferences. You prune the list, and the next review uses it.

Connect only what you use

Jira, Figma or any MCP server can be added from Settings. With none, it reviews from the repository and the PR alone.

Run it in five minutes

Second Look runs on your machine. You need:

  • Node 24 and pnpm 10
  • Git
  • A GitHub token with repo read and pull request write
  • The Claude Code CLI, signed in with claude login

Then open the web app, add a repository and paste a pull request link. Integrations are optional and live under Settings.

$ git clone <your copy of second-look>
$ cd second-look
$ cp .env.example .env   # add GITHUB_TOKEN
$ pnpm install
$ pnpm dev

Questions

Where does my code go?

Repositories are cloned into a data folder on your machine. The agent reads them there through the Claude Code CLI, so the parts it reads are sent to Anthropic's API under your own Claude account. Nothing is sent to us.

Does it post anything without asking?

No. The agent is read-only. It cannot edit files, run your build or post to GitHub. Only findings you accept are posted, when you press Post.

Do I need Jira or Figma?

No. Without them, the agent works from the pull request description and the code. Connect them in Settings if you want tickets and designs read too.

Can I teach it our conventions?

Yes. Each repository points to a review guide, and the agent also reads the docs in the repository and what it remembered from earlier reviews.
